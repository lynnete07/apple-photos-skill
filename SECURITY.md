# Security policy / 安全策略

Do not publish personal photo-library identifiers, private filenames, GPS coordinates, local paths, or media metadata in an issue.

请勿在 issue 中公开照片库标识、私人文件名、GPS 坐标、本地路径或媒体元数据。

For a normal defect, open a GitHub issue with a synthetic reproduction. For a vulnerability that could cause unauthorized access, unintended deletion, or private-data exposure, use GitHub's private vulnerability-reporting channel when available. If that channel is unavailable, contact the maintainer through the GitHub profile without attaching private library data.

普通缺陷请使用虚构数据创建 issue。若问题可能导致越权访问、意外删除或隐私数据泄露，请优先使用 GitHub 私密漏洞报告；如果入口不可用，请通过维护者 GitHub 主页联系，且不要附带真实照片库数据。

Supported security fixes target the latest version on the default branch.
